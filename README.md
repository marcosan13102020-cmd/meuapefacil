## Qual arquivo é qual página

| Arquivo | Página no site |
|---|---|
| index.html | Página inicial |

## Como trocar um texto

1. Clique no arquivo da página
2. Clique no lápis (canto direito)
3. Ctrl+F e procure o texto
4. Troque só o que está entre > e <
5. Commit changes (botão verde)
6. Espere 1 minuto e abra o site com Ctrl+F5

## Como trocar a foto

1. A foto precisa se chamar exatamente Marcos.jpeg
2. Add file > Upload files > arraste a foto
3. Commit changes

Cuidado: o Windows esconde o final do nome. Confira se não ficou Marcos.jpeg.jpeg.
